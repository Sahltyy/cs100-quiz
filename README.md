# CS100 Quiz

A cute practice quiz and flashcard deck for my CS100 test. All 19 study-guide questions, with sounds, read-aloud, and both answers marked on the extra-credit questions.

**Open it:** https://sahltyy.github.io/cs100-quiz/

On iPhone, open the link in Safari, tap **Share**, then **Add to Home Screen**. Open it once while online and it works offline after that.

## Topics

- Text formats: HTML, JSON, UTF-8, RTF
- Networking: DHCP, MAC addresses, DNS, private IP ranges
- Security: authentication, anonymous users, asymmetric encryption, HTTPS, digital signatures
- Intellectual property: copyright, trademark, first sale doctrine, patents
- Email: SMTP, IMAP and POP3
